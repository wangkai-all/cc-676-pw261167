# 入仓修复工作台

在不修改任何单元格内容的前提下，从候选记录中选出**能一起发布的最大权重子集**：
冲突的记录不能同时入仓，子行依赖的父行必须同时保留。网页先展示冲突关系，
再给出保留与隔离方案，点击任意一行能看到它为什么被舍弃。

## 快速开始

```bash
./run.sh            # 启动 http://127.0.0.1:8074/
```

- 有 scipy 时用 **HiGHS 整数规划**（`scipy.optimize.milp`）求解；
  没有 scipy 时自动退回**内置分支定界**（纯标准库），接口与语义一致。
- 演示数据：`data/` 下 3 张表共 **40 行**候选（类别 8 / 商品 14 / 明细 18）。

## 工作流程

1. **① 冲突关系**：图谱展示全部候选行。红线 = 冲突（主键重复 / 函数依赖），
   灰色虚线箭头 = 外键依赖（子→父）。点击节点查看行详情、标记必留（★）。
2. **② 保留与隔离方案**：整数规划跨表联合求解（保留父行才允许更多子行入选，
   不是把碰到冲突的行全部隔离）。点击隔离清单中的一行，看它的舍弃原因
   （与谁冲突、需要哪个父候选、权重对比）。
3. **③ 校验与发布**：修复器只生成候选清单；**独立校验器**（`workbench/verifier.py`，
   不导入求解器任何代码，以隔离子进程运行）重新核验通过后，发布器才写出
   `releases/v<N>/warehouse/*.csv`（仓表）与 `releases/v<N>/quarantine/*.csv`
   （隔离文件，含原因列）。旧版本永不覆盖。

## 规则语义（固定，不再变动）

- 空值 = CSV 空字符串。每表一个**单列主键**：主键为空的行强制隔离；
  同表主键重复的行两两冲突。
- **函数依赖** `det -> dep`（`constraints.json` 中显式声明，可多列）：
  `det` 含空值的行不参与；其余行 `det` 相同则 `dep` 必须完全一致
  （空值按普通值比较）。例：同一类别名只能对应一个类别编号。
- **单列外键**：子行外键为空 → 无要求；非空 → 至少保留一行匹配的父行
  （析取）。无匹配父候选 → 孤儿行，强制隔离（级联传播）。
- 每行一个数值**保留权重**（`weight` 列），目标为总权重最大。

## 求解保证

- **整数规划模型**：`x_i∈{0,1}`；冲突边 `x_i+x_j≤1`；外键 `x_c≤Σx_p`；
  必留 `x_i=1`；孤儿/空主键 `x_i=0`；目标 `max Σ w_i x_i`。
- **穷举校对**：按弱连通分量分解后，每个 ≤18 行的分量用穷举法独立求最优，
  与整数规划结果逐分量比对，网页显示校对结论（测试另含随机小实例对拍）。
- **平局裁决**：同权重多解时，第二阶段在 `Σwx = W*` 下按**固定行身份**
  （表名+源文件行号）的字典序偏好选出唯一规范解；其余等价最优解不丢弃——
  小组件精确计数（演示数据共 2 个），并可切换查看等价方案。
- **超时**：展示当前可行解与上界（`mip_dual_bound` / 分支定界全局上界）及差距；
  **未证明最优绝不声称最优**（状态仅为“可行解”）。
- **必留不可行**：给出具体冲突——直接冲突对、被强制隔离的必留行、
  经外键传递被迫同时保留的冲突链，以及极小不可行核心；不会悄悄取消必留。

## 候选失效与版本

- 输入指纹 = 全部行内容 + 权重 + 约束的 SHA-256。**修改权重或约束后，
  原候选立即失效**（发布返回 409），需重新求解；源文件与旧发布版全部保留。

## 目录结构

```
data/               演示业务表（CSV，含 weight 列）+ constraints.json（FD/FK 声明）
workbench/
  model.py          载入、校验、固定语义、输入指纹
  graph.py          冲突图：主键重复、FD 冲突、外键、孤儿级联、连通分量
  solver.py         整数规划（scipy milp / 内置分支定界）、平局裁决、等价解、穷举校对
  explain.py        舍弃原因、必留不可行诊断
  verifier.py       独立校验器（可独立运行：python3 -I verifier.py DATA 候选.json）
  publisher.py      校验通过后写 releases/v<N>/{warehouse,quarantine}
  server.py         HTTP API + 静态页面（仅标准库）
web/                单页前端（冲突图谱 SVG / 方案 / 发布）
tests/test_all.py   22 项测试：python3 tests/test_all.py
releases/           发布输出（运行时生成）
```

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 表、约束、冲突图、指纹、发布记录 |
| POST | `/api/solve` | `{must_keep, time_limit}` → 候选（含解释、校对、等价解） |
| POST | `/api/publish` | `{candidate_id}` → 校验并写出仓表；候选失效返回 409 |
| POST | `/api/reload` | 重新载入数据文件（权重/约束变更后） |
